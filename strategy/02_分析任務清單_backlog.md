## 🟥 P0 — 資料地基 (Data Pipeline)

沒有乾淨資料，後面所有篩選都是空談。先把這幾張表每日更新起來。

- [ ] **T01 日 K 線資料**：全台股上市櫃日 OHLCV（開高低收量），存 SQLite/Parquet
  - 來源：TWSE `STOCK_DAY_ALL` / TPEX、或 FinMind / yfinance
- [ ] **T02 三大法人買賣超**：每日外資 / 投信 / 自營商買賣超（張數、金額）
- [ ] **T03 月營收**：MOPS 每月營收（YoY / MoM），含歷史
- [ ] **T04 財報**：季 EPS、營收、毛利率、營益率
- [ ] **T05 除權息 / 股利**：除息日、現金/股票股利、殖利率
- [ ] **T06 融資融券 / 當沖**：融資餘額增減、當沖比（散戶熱度）

> 每張表一個 `fetch_xxx.py`，統一寫入 `data/` 目錄。

## 🟧 P1 — 選股篩選器 (Screeners)（你點名的重點）

### T10 「黑馬股」篩選器 🐎
> 目標：找出**剛啟動、還沒被市場注意、準備發動**的股票。

建議條件（可調參數，全部 AND，或加權評分）：
1. **趨勢轉多**：股價站上季線(60MA) 且 季線由下彎轉上彎
2. **爆量表態**：近 5 日出現「量 > 20 日均量 ×2」的長紅 K
3. **突破**：突破近 20~60 日整理區間高點 / 前波高
4. **基本面配合**：最近月營收 YoY > 20% 且 MoM 轉正（動能加速）
5. **籌碼點火**：近 3~5 日投信或外資買超
6. **流動性/市值門檻**：日均量 > X 張、市值 > Y 億（排除冷門易被坑殺）
7. **未過熱**：近月漲幅 < 40%（避免追在噴出末端）

輸出：股票代號、觸發了哪幾條、量能倍數、法人買超張數 → **黑馬候選清單**。

---

### T11 「法人默默吸貨」篩選器 🤫
> 目標：找出**法人低調連續買、但股價還沒大漲（吃貨階段）**的股票。

建議條件：
1. **連續買超**：投信（或外資）近 5~10 日**連續**買超（認養特徵）
2. **價格還沒噴**：同期間股價漲幅 < 10%（低調吸籌，非追高）
3. **吃貨力道**：法人買超張數 / 該期間總成交量 > 門檻（例 15%）
4. **籌碼乾淨**：融資**未大增**（散戶還沒追）→ 籌碼集中在法人
5. **打底型態**：股價在均線附近盤整 / 底部墊高，非高檔
6. **排除**：已大漲噴出、處置股、財報地雷

輸出：代號、法人連買天數、累計買超張數、佔量比、期間漲幅 → **默默吸貨候選**。

> ⚠️ 提醒：法人買不代表一定漲；法人也會看錯/調節。此清單是**縮小研究範圍**，
> 不是保證噴出名單。務必再看基本面與大盤環境。

## 🟨 P2 — 指標庫、監控、回測

### T20 技術指標庫
- 均線群 (5/10/20/60/240)、乖離率、均線糾結
- MACD、KD、RSI、布林通道、ATR（波動/停損用）
- 量價指標：量能倍數、量價背離、OBV

### T21 籌碼指標庫
- 三大法人連買/連賣天數、累計買超
- 投信認養股清單、主力分點進出（若有資料源）
- 籌碼集中度、大戶持股比變化

### T22 每日盤後掃描報告（自動化）
- 每日跑一次全市場，輸出：黑馬候選、法人吸貨候選、抗跌強勢股、跌破停損警示
- 產出 Markdown / HTML 報告，存 `reports/daily/`
- 可加 email / 通知推播

### T23 策略回測框架 (Backtest)
- 用歷史資料驗證篩選器的勝率、賠率、最大回檔（MDD）
- 避免「看起來很準」的過度擬合 → 分訓練/驗證期間
- 加入交易成本（手續費 0.1425% ×折、證交稅 0.3%）

### T24 部位與風險管理工具
- 單筆最大部位上限、總曝險控管
- 停損停利計算（固定 % / ATR 倍數 / 移動停利）
- 個人持股績效追蹤 dashboard
