> 以及建議的實作順序。此檔為決策/實作依據，動工前先讀。

**關鍵資料落在哪一級：**

## 🅰️ 每日報表 能變更好的事

> 限制：分點是「券商 × 個股 × 每天」，全市場每天跑不完。分點類升級**只加在篩選後候選股**（N 小、API 撐得住）。

### 1. 填補「隔日沖盲區」
- **隔日沖偵測欄**：候選股比對 T-1 買 / T 賣分點 → 標「⚠️隔日沖出貨中」或「隔日沖常客進場」。
- **隔日沖大戶點名**：今日前幾大買方若為公認隔日沖分點（凱基-台北 / 摩根 / 美林…）→ 警示「隔天恐殺低」。
- 補上「當沖比看不到隔日沖」的洞（當沖=當日沖銷；隔日沖=今買明賣，落在一般買賣）。

### 2. 主力籌碼：免費近似 → 真分點
- `src/broker_client.py` 已接好，填 token 即通：主力買超/賣超（前 15 大分點淨額）、買賣家數、籌碼集中度。
- 主力軌（`main_force`）不再用估算分數，直接看真實分點。

### 3. 大戶：單週對比 → 多週趨勢
- 解鎖千張大戶歷史 → 大戶連續幾週增/減（趨勢），取代現在只有本週 vs 上週。
- ⚠️ 仍週頻（TDCC 源頭限制，Sponsor 不會變日頻）。

### 4. 🔥 操作面最大紅利：額度解放
- 600/hr → 6000/hr。
- 原本被迫 `--skip-longterm`（長期軌逐檔深掘燒爆額度）→ **長期軌可回歸每天**，五軌完整日更。
- 候選股可 enrich 更多分點/借券，不再撞牆。
- 直接解掉當初「長期軌拆週更」的痛點。

## 🅱️ 個股深掘 能做到的事

> 單檔、on-demand、全歷史。6000/hr 對一檔綽綽有餘。

1. **隔日沖完整圖譜**：過去 N 天哪些分點反覆隔日沖這檔 → 「這檔的隔日沖常客名單＋命中頻率」；判斷是否隔日沖愛股/洗盤慣性股。
2. **主力分點進出時間軸**：逐日前 N 大買/賣分點淨額 → 主力何時進場、哪個價位開始出貨；比三大法人細（看得到特定券商）。
3. **特定分點追蹤**：鎖定某券商分點（外資摩根、實戶大戶分點）歷史進出 → 跟單/避雷。
4. **借券空單完整曲線**：法人空單餘額 vs 股價疊圖 → 軋空/避險判斷、歷史高低位。
5. **大戶持股歷史曲線**：週頻大戶% 趨勢配股價 → 吸籌 or 派發。
6. **籌碼集中度時間序列**：分點集中度隨時間 → 由散到聚（吃貨）/ 由聚到散（出貨）。
7. **單檔籌碼病歷表**：一頁看完 法人/大戶/融資券/借券/分點/隔日沖/當沖/月營收 全歷史 → 決策前深掘。

## 本質差異

| | 每日報表 | 個股深掘 |
|---|---|---|
| 廣度 | 掃全市場、輸出候選 | 單檔 |
| 分點用法 | 只加在候選股（今/昨兩天）| 全歷史時間軸 |
| 最大紅利 | 額度解放→長期軌回歸每天＋隔日沖旗標 | 分點級主力故事＋隔日沖常客名單 |
| 使用時機 | 每天盤後自動跑 | 想決策某檔時手動跑 |

## ⚠️ 即使 Sponsor 也做不到（不開空頭支票）

- **全市場每日分點跑不完**（~1800 檔×分點，6000/hr 仍不夠）→ 每日報表分點只能限候選股。
- **千張大戶仍週頻**（TDCC 源頭限制）。
- **分點歷史有起始日**：FinMind 只回溯到某年，非無限。
- **隔日沖是「推論」非官方標籤**：靠分點買賣超比對，有誤判可能。
- **FinMind 分點是盤後彙總**：無盤中即時、無逐筆。

## 建議實作順序（我即將升級）

> 原則：先做免費無悔的、再做架構基礎、最後做兩個產品的殺手級功能。每步可獨立驗證。

### 階段 0 — 免費無悔（升級前就能做）
- **[0] 借券歷史回補**：`TaiwanDailyShortSaleBalances` 免費，現行 `sbl_signal` 只查當日、不落地。
  回補歷史存 DB/CSV → 借券增減＋趨勢欄。不管辦不辦付費都用得到。

### 階段 1 — 升級後：基礎建設（先打通資料層）
- **[1] 確認 Sponsor 生效**：`.env` 填 `FINMIND_TOKEN`；跑 `broker_client.available()` 應回 True。
- **[2] 額度解放驗證**：確認 6000/hr → 移除日常盤後的 `--skip-longterm`，五軌回歸日更（GUI/bat 改回）。
  這步不寫新功能、CP 值最高（解掉舊痛點）。
- **[3] 千張大戶歷史回補**：`TaiwanStockHoldingSharesPer` 歷史 → 大戶趨勢欄（多週增減、拐點）取代單週對比。

### 階段 2 — 每日報表殺手級功能
- **[4] 主力分點欄上線**：`broker_client.enrich_branches` 已寫好，接進主力軌 → 主力買賣超/集中度真數據。
- **[5] 隔日沖偵測欄**：候選股比對 T-1 買/T 賣分點 → 隔日沖旗標＋常客分點點名。
  先建「隔日沖常客名單」（可先用市場公認清單，再用歷史自動累積校正）。

### 階段 3 — 個股深掘工具（獨立指令 / GUI 按鈕）
- **[6] 個股深掘 MVP**：輸入單檔 → 拉齊分點歷史＋借券歷史＋大戶歷史，輸出「單檔籌碼病歷表」（.md + .html）。
- **[7] 深掘進階**：主力分點時間軸、隔日沖圖譜、籌碼集中度時間序列、特定分點追蹤。

### 階段 4 — 驗證（別跳過）
- **[8] 回測隔日沖訊號**：隔日沖旗標到底有沒有 edge？納入 `signals.py` / portfolio 回測框架，
  比照 T11/T16 做樣本外，別把「看起來有用」當保證。

**建議先後**：0 →（升級）→ 2 → 1 →〔3 或 4〕→ 5 → 6 → 7 → 8。
其中 **[0][2] 是最高 CP 值**（免費無悔 + 解掉舊額度痛點），**[5] 是你最想要的隔日沖**，
**[6] 是個股深掘的核心**，**[8] 確保不自欺**。
