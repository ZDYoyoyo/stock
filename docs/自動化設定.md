# 每日自動化設定（雲端 + 本機）

每天盤後自動「拉資料 → 三軌選股+T12+排雷+主力籌碼 → 推播到手機」。
⚠️ 研究用途，非投資建議。

---

## 🤖 給接手 session 的說明（未來換 session 先讀這段）

> 若你是新的 Claude session、被每日排程叫起來，或使用者要你接手雲端每日分析：
> 1. 這是台股研究系統，repo `ZDYoyoyo/stock`，分支 `claude/taiwan-stock-analysis-asx-mww0s6`。
> 2. 先讀 `PROJECT_STATE.md` 了解整體；本檔說明「每日自動化」怎麼運作。
> 3. **secret 不在 git 裡**（`.env` 被 gitignore）。雲端靠**環境變數 secret**帶入
>    `FINMIND_TOKEN` / `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID`；讀不到就代表使用者還沒設，
>    此時資料/報告仍可產出，但**推播會失敗**——回報使用者去環境設定補 secret。
> 4. 每日要跑的管線見下方「每日管線」。非交易日（週末/假日）或當日資料未出 → 不動作。

### 每日管線（排程與手動都跑這個）
```bash
python -m scripts.sync_data load        # ① 用 CSV 歷史重建 DB（累積用；雲端必跑）
python -m scripts.run_all --notify      # ② 更新資料+環境+T11/T16+T12+T11排雷+當沖+長期+持股+推播
python -m scripts.run_landmine --holdings   # ③ 有持股才有意義：持股排雷
python -m scripts.run_mainforce         # ④ 主力籌碼進駐排行（免費綜合；有Sponsor自動加分點）
python -m scripts.sync_data dump --keep-days 900   # ⑤ 把新資料寫回 CSV
# ⑥ git add data/history && git commit -m "資料更新 YYYY-MM-DD" && git push origin claude/taiwan-stock-analysis-asx-mww0s6
```
`run_all` 已含大部分；③④是加值。分析重點：先看🚦環境紅綠燈，再看各軌 + T11風險欄。

### 📦 資料持久化（CSV，讓歷史累積）
- 雲端 session 暫時、`data/stock.db` 被 gitignore；歷史靠 **CSV 存在 `data/history/`（進 git）**。
- 流程：`sync_data load`（開場用 CSV 重建 DB）→ 抓當天增量 → `sync_data dump`（寫回 CSV）→ commit。
- 這樣**價量/法人/融資/千張大戶會一天天累積**（千張大戶週趨勢尤其需要多週累積）。
- CSV 是文字、git diff 乾淨；`--keep-days 900` 只留近約 3.5 年，控制檔案大小。
- 回測不吃這份長期 DB（它直接向 FinMind 抓多年）；但自訂分析與千張趨勢靠這份累積。

## ☁️ 雲端自動化（Claude Code on the web）

### 需要使用者做的（只有你能做，一次就好）
1. **設環境變數 secret**（這樣每個 session／排程都自動帶，且不進 git）：
   在 https://claude.ai/code 開你這個環境的設定 → 環境變數，加：
   - `FINMIND_TOKEN`（深掘/回測用；免費即可，辦 Sponsor 可解鎖分點）
   - `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`（推播到手機用；設定見 `每日每週操作.md`）
2. **確認網路政策**允許連 TWSE/TPEX/FinMind/Yahoo（本環境目前可連，代表已允許）。
3. 告訴我要跑的**時間**（預設：台灣時間週一~五 19:00，三大法人 T86 已公布）。

### 排程（Claude 這邊設定，使用者不用管）
- 用 Routine（scheduled trigger）每交易日盤後觸發，跑「每日管線」並推播。
- 目前設定：**每週一~五 台灣 19:00（= 11:00 UTC）**，每次開新 session 執行、讀本檔管線。
- 產出報告在 `reports/screener/`（gitignore，不入庫）；交付走 **Telegram 推播**。
- 若沒設 Telegram secret：報告照產出但推不出去 → 補 secret 即可。

### 注意（雲端限制）
- 雲端環境是**暫時性**的：session 會被回收、新 session 重新 clone。
- 所以 secret **一定要放環境變數**（不能靠 `.env`，那不持久也不進 git）。
- 每日排程用「開新 session」模式，天然不受單一 session 回收影響。

## 🖥️ 本機自動化（Windows，使用者有空再設）

本機好處：token/secret 放本機 `.env` 就持久，不怕雲端回收；缺點要開著電腦。

### 一次設定
1. 裝好 Python 3.9+、Git；`git clone` 專案到 `E:\stock`（見 README）。
2. `copy .env.example .env` → 填 `FINMIND_TOKEN` 與 `TELEGRAM_*`（見「FinMind token 設定」「Telegram 推播設定」）。
3. 測試：`python -m scripts.run_all --notify` → 手機收到推播就 OK。

### 排程（Windows 工作排程器）
1. 開「工作排程器」→ 建立基本工作 → 觸發：每天（或每週一~五）19:00。
2. 動作：啟動程式
   - 程式：`python`（或 python.exe 完整路徑）
   - 引數：`-m scripts.run_all --notify`
   - **起始位置**：`E:\stock`（一定要填，否則找不到模組/資料）
3. 進階可再加一個 09:00 的工作跑 `-m scripts.monitor_portfolio`（盤中持股守衛）。

### 一鍵替代
不想設排程 → 每天盤後點 `一鍵執行\1_盤後選股.bat`（等同 run_all --notify）。
