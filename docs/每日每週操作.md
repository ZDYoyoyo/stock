## 🗓️ 每週一次（週末，集保是週資料）

```bat
python -m scripts.update_holders
```
更新**千張大戶籌碼**（≥1000張大戶持股比）。連續幾週跑才會累積出「週增減」趨勢。
→ 更新後，**每日 `run_all` 的 T11 波段清單就會直接顯示「千張大戶%」欄**（也可在 `run_t30` 看）。

## 📅 每天的流程

### ① 盤前 / 盤後（傍晚）— 選股 + 環境 + 持股結算
```bat
python -m scripts.run_all --notify
```
- 產出整合報告（`reports\screener\` 下 `.md` 和 `.html`，**用瀏覽器開 .html**）
- 內容：🚦環境紅綠燈、全球市場(費半)、🟡波段(T11/T16/交集)、🟢長期、🔴當沖候選、📋我的持股
- `--notify` 會把摘要 + 觸停損提醒推到手機（需先設 Telegram，見下）
- 想快一點：加 `--skip-longterm`（略過較慢的長期軌）

### ② 盤中（09:00~13:30）— 持股守衛掛著
```bat
python -m scripts.monitor_portfolio
```
- 持續盯你的持股，**一觸停損/停利就自動推 Telegram**（每檔只推一次）
- 開一個 cmd 視窗放著，手機等通知就好，不用一直盯盤

### ③ 研究個股時（想深入某檔）
```bat
python -m scripts.run_t30          :: 對波段短名單補基本面 + 千張大戶
python -m scripts.risk_calc --stock 2206 --account 1000000 --risk 1.5   :: 算停損/部位
```

### ④ 記錄 / 查看持股
```bat
python -m scripts.portfolio add 2330 --lots 2 --price 1000 --stop 950 --target 1100
python -m scripts.portfolio          :: 看即時損益
python -m scripts.portfolio remove 2330
```

## 📲 Telegram 推播設定（一次就好，約 5 分鐘）

Line Notify 已於 2025/3/31 停用，改用免費的 Telegram。

**手機上：**
1. 開 Telegram，搜尋 **`@BotFather`**（官方，有藍勾勾）
2. 傳 `/newbot` → 幫 bot 取名 → 完成後拿到一串 **BOT TOKEN**（像 `123456789:ABCdef...`）
3. **搜尋你剛建的 bot，點進去傳一則訊息**（隨便打 `hi`）← 不能跳過，否則 bot 收不到你

**電腦瀏覽器：**
4. 開這個網址（`<TOKEN>` 換成你的）：
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
5. 找 `"chat":{"id":123456789}` → 那數字就是 **CHAT_ID**

**在 stock 資料夾：**
6. 建立並編輯 .env：
   ```bat
   copy .env.example .env
   notepad .env
   ```
7. 填入這兩行後存檔：
   ```
   TELEGRAM_BOT_TOKEN=你的TOKEN
   TELEGRAM_CHAT_ID=你的數字
   ```
8. 測試：
   ```bat
   python -m scripts.run_all --no-update --skip-longterm --notify
   ```
   手機收到訊息就成功 🎉

### 常見卡點
- **收不到** → 多半是忘了「先傳訊息給 bot」(步驟3)；或 TOKEN/CHAT_ID 貼錯、含空白
- **getUpdates 回 `{"ok":true,"result":[]}`** → 就是還沒傳訊息給 bot，回步驟3再重開網址
- **.env 沒生效** → 確認檔名是 `.env`（不是 `.env.txt`；記事本存檔時「存檔類型」選「所有檔案」）
- Email 推播：改填 `.env` 的 `SMTP_*`（Telegram 優先於 Email）
