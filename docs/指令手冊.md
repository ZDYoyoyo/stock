# 指令手冊（所有功能怎麼跑）

> 在 `stock` 資料夾裡執行；Windows 先跑一次 `chcp 65001`。
> 前置：先有資料 → `python -m scripts.update_data`（第一次加 `--days 40`）。

---

## 一、每天必跑

| 目的 | 指令 |
|---|---|
| 更新資料（盤後） | `python -m scripts.update_data` |
| 一鍵跑全部+環境（產出 .md 和 .html） | `python -m scripts.run_all` |
| 只跑波段（快，不含長期） | `python -m scripts.run_all --skip-longterm` |
| 更快（連 T11 排雷也略過） | `python -m scripts.run_all --skip-longterm --skip-landmine` |
| **跑完推播摘要到手機** | `python -m scripts.run_all --notify` |

> `run_all` 現在含：🚦環境 + 波段(T11/T16) + **🚀成長T12** + 長期 + 當沖 + 持股，
> 且 **T11 清單會就地排雷、標「風險」欄**（選股當下就看到雷；有🔴/🟠會列紅旗提醒）。
> 排雷需 FinMind 逐檔查 T11 候選（清單小、成本低）；想更快可加 `--skip-landmine`。

### 推播設定（Telegram，取代已停用的 Line Notify）
1. 手機 Telegram 搜 `@BotFather` → 傳 `/newbot` → 取得 **BOT TOKEN**
2. 對你的新 bot 傳一則訊息，再瀏覽器開
   `https://api.telegram.org/bot<你的TOKEN>/getUpdates` → 找 `"chat":{"id":數字}` = **CHAT_ID**
3. 把 TOKEN、CHAT_ID 填進 `.env`（參考 `.env.example`）
4. 跑 `python -m scripts.run_all --notify` → 手機就會收到摘要 + 完整 HTML 檔
（也支援 Email，填 `.env` 的 SMTP_* 即可；Telegram 優先。）

報告在 `reports\screener\`，**用瀏覽器開 `_run_all.html`** 最清楚。

## 三、深掘（研究個股用）

| 目的 | 指令 | 說明 |
|---|---|---|
| **基本面深掘** | `python -m scripts.run_t30` | 對 T11 短名單補月營收/EPS/PER**＋千張大戶籌碼** |

### 🧨 地雷偵測（買進/續抱前排雷，是「排除」非選股）
| 目的 | 指令 |
|---|---|
| **查我的持股**（預設） | `python -m scripts.run_landmine --holdings` |
| **查指定股**（要買前先掃） | `python -m scripts.run_landmine --stocks 2330,2603` |
| **掃今日候選**（避免買到雷） | `python -m scripts.run_landmine --from-daily` |
| 只列風險≥某級 | `python -m scripts.run_landmine --holdings --min-level 高` |

查財務(營收/EPS/毛利)+籌碼(法人賣/大戶出貨/融資暴增)+技術(破季線/相對弱勢)紅旗，
加權給風險級 🟢低/🟡中/🟠高/🔴嚴重。門檻在 `src/config.py` 的 `LANDMINE`。

### 持股追蹤器（記錄實單、算損益、停損警示）
| 目的 | 指令 |
|---|---|
| 看持股與即時損益 | `python -m scripts.portfolio` |
| 新增/更新一筆 | `python -m scripts.portfolio add 2330 --lots 2 --price 1000 --stop 950 --target 1100` |
| 移除 | `python -m scripts.portfolio remove 2330` |

持股存在 `data\portfolio.csv`（可用 Excel 編輯，不會上傳）。到停損/停利價會跳 🔔 警示。
盤中即時價用 MIS、盤後用收盤；損益為毛額（未計手續費+證交稅約0.6%）。

| **盤中持股守衛**（掛著跑，觸停損自動推 Telegram） | `python -m scripts.monitor_portfolio` |
| 守衛-調整檢查頻率 | `python -m scripts.monitor_portfolio --interval 30` |

盤中(09:00~13:30)在本機掛著跑，每檔觸停損/停利只推一次。需設 Telegram 才會推手機。

> 千張大戶「週增減」要**連續跑幾週**才會有數字（第一次只有當週水位）。

## 四、回測（驗證訊號有沒有效）

| 種類 | 指令 | 時間 |
|---|---|---|
| 單/少檔快測 | `python -m scripts.run_backtest --stocks 2206,6669 --hold 10 --k 4` | 快 |
| 一籃子驗證 | `python -m scripts.run_validation --hold 10 --k 4` | 中 |
| 訊號 vs 大盤基準 | `python -m scripts.run_edge_check` | 中 |
| **完整回測** | `python -m scripts.run_full_backtest --universe 60 --start 2022-01-01` | **20~40分（會限流等待，正常）** |

參數：`--hold` 持有天數、`--k` 法人連買門檻天數、`--start` 起始日、`--stocks` 指定股。
完整回測結論已存 `reports\backtest_validation.md`。

## 六、常見問題

- **一定要先 `update_data`** 才能跑選股/回測（靠 DB）。
- **回測/深掘很慢**是正常的（FinMind 免費限流會自動等待，看到 `402 等60s` 別緊張）。
- **表格看起來歪** → 用瀏覽器開 `.html`，或 VSCode 按 `Ctrl+Shift+V` 預覽 `.md`。
- **改門檻**：全部在 `src/config.py`（殖利率、連買天數、振幅…）。
- 功能白話解釋見 `docs/功能說明.md`。
