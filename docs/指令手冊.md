| 🌅 盤前快報（開盤前看，含昨夜美股/費半） | `python -m scripts.run_morning` |

> 且 **T11 清單會就地排雷、標「風險」欄**（選股當下就看到雷；有🔴/🟠會列紅旗提醒）。

### FinMind token 設定（選填；深掘/回測用免費 token，分點用付費 Sponsor）

FinMind 分兩種，都填在 `.env` 的同一個 `FINMIND_TOKEN`：

**A. 免費 token（建議先辦，提高額度，深掘/回測較不會卡限流）**
1. 開 https://finmindtrade.com/ → 右上「註冊/登入」（用 Email 或 Google）
2. 登入後進「會員中心 / API Token」頁 → 複製你的 **API Token**（一長串）
3. 在 stock 資料夾：`copy .env.example .env` → 用記事本開 `.env`
4. 填這行後存檔（存檔類型選「所有檔案」，別存成 .env.txt）：
   ```
   FINMIND_TOKEN=你複製的那串token
   ```
5. 免費 token 就生效了（run_t30 / run_landmine / 回測會用它，額度較高）。

**B. 付費 Sponsor（要看「券商分點主力進出」才需要）**
1. 同一個 FinMind 帳號 → https://finmindtrade.com/analysis/#/Sponsor/sponsor 訂閱贊助方案
2. **token 不變**（還是同一串），升級後那串 token 的權限自動涵蓋分點
3. 什麼都不用改，直接跑 `python -m scripts.run_mainforce` → 開頭會顯示
   `分點資料：✅ 可用（FinMind Sponsor）`，並多出「分點主力買賣超」欄

**驗證有沒有生效**：
```bat
python -m scripts.run_mainforce
```
開頭那行：`⚪ 免費模式` = 沒 token 或免費等級；`✅ 可用（FinMind Sponsor）` = 分點已解鎖。

> ⚠️ token 等同密碼，別貼到公開場合、別 commit 進 git（`.env` 已被 .gitignore 排除）。

### 推播設定（Telegram，取代已停用的 Line Notify）
1. 手機 Telegram 搜 `@BotFather` → 傳 `/newbot` → 取得 **BOT TOKEN**
2. 對你的新 bot 傳一則訊息，再瀏覽器開
   `https://api.telegram.org/bot<你的TOKEN>/getUpdates` → 找 `"chat":{"id":數字}` = **CHAT_ID**
3. 把 TOKEN、CHAT_ID 填進 `.env`（參考 `.env.example`）
4. 跑 `python -m scripts.run_all --notify` → 手機就會收到摘要 + 完整 HTML 檔
（也支援 Email，填 `.env` 的 SMTP_* 即可；Telegram 優先。）

報告在 `reports\screener\`，**用瀏覽器開 `_run_all.html`** 最清楚。

## 三、深掘（研究個股用）

### 🔍 個股籌碼診斷（外資/投信/自營 + 融資融券 + 今日漲跌原因）

```
python -m scripts.diagnose 2330            # 診斷台積電
python -m scripts.diagnose 4939 --days 15  # 看更長天數
```
輸出：三大法人**逐日拆細**（外資/投信/自營/合計）＋融資餘額/增減＋融券餘額/增減＋量能，
並用**今日 vs 昨日**的籌碼變化做「漲跌歸因」（例：法人買/散戶追/軋空/散戶接刀…）。
GUI 對應按鈕：**🔍 籌碼診斷**（填代號後按）。

|---|---|---|

### 永豐金 Shioaji 即時行情設定（選填；盤中即時升級）

**定位**：把盤中監控的報價從「20 秒延遲」升級成「券商級即時」。本系統**只用行情、不下單**。

**申請要開什麼權限**（重點）：
- ✅ **開「正式環境 ＋ 行情」** —— 行情屬「非個人資料」，只需 API Key 登入驗證。
- ❌ **不用開「下單」** —— 下單才需要電子憑證＋臨櫃簽「API 電子交易風險預告書」＋模擬測試審核；純看行情完全不需要。

**步驟**：
1. 需有永豐金證券帳戶（可線上開戶）。
2. 到永豐金「API 服務」網頁申請 API，取得 **API Key** 與 **Secret Key**。
3. `pip install shioaji`
4. 把金鑰填進 `.env`（本機）或環境變數（雲端）：
   ```
   SHIOAJI_API_KEY=你的_api_key
   SHIOAJI_SECRET_KEY=你的_secret_key
   ```
5. 核對：`python -m src.shioaji_client` → 印出 2330/2317/6243 即時報價就 OK。

**限制**（永豐金官方）：訂閱上限 200 檔、每身分證最多 5 連線、每 24h 需重新登入；行情流量額度**依下單量而定** → 適合盯**小清單**（持股＋當沖候選），別大量抓歷史。沒設定或抓不到時系統自動退回免費 MIS。

## 六、常見問題

- **一定要先 `update_data`** 才能跑選股/回測（靠 DB）。
- **回測/深掘很慢**是正常的（FinMind 免費限流會自動等待，看到 `402 等60s` 別緊張）。
- **表格看起來歪** → 用瀏覽器開 `.html`，或 VSCode 按 `Ctrl+Shift+V` 預覽 `.md`。
- **改門檻**：全部在 `src/config.py`（殖利率、連買天數、振幅…）。
- 功能白話解釋見 `docs/功能說明.md`。
