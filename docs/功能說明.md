# 功能總說明（白話版）

這份把系統每個模組/代號用白話講清楚。⚠️ 全部研究用途，非投資建議。

---

## 一、每天怎麼用（流程）

```
盤後(傍晚) → python -m scripts.run_all → 看報告
  1. 先看🚦環境紅綠燈：現在該不該出手
  2. 再看各軌清單：波段T11/T16、🚀成長T12、長期、當沖各自的候選
     （T11 清單已直接標「風險」欄：選股當下就看到有沒有雷）
  3. 想深入某檔 → run_t30(基本面) + run_landmine(排雷) + risk_calc(算停損部位)
盤中(要盯盤時) → python -m scripts.monitor_intraday
```

## 二、選股代號是什麼意思

### 🟡 波段軌（持有天~數週）
- **T11 法人吸貨**：找「法人**連續買超**、但股價還沒噴、籌碼乾淨」的股票。
  - 上市看**投信**（投信認養是強訊號）、上櫃看**外資**（投信少碰上櫃）。
  - 報告欄位（表頭已中文化）：
    - **連買天數**=法人連續買超幾天；**吃貨比重%**=法人買量佔成交量比（吃貨力道）。
    - **區間漲幅%**=**近 10 個交易日的累積漲幅**（收緊到 -8%，濾掉一直跌的接刀股）。
      ⚠️ **不是單日漲跌**——別把它當今天漲幾%。
    - **收盤**=**法人資料基準日(asof)的收盤價**，**不一定是最新交易日**。
      因為三大法人(T86)上市常比上櫃晚一天公布，T11 會把兩市場對齊到「共同最後法人日」，
      所以那天可能是前一個交易日（報告區塊上方會標「法人資料截至 YYYY-MM-DD」）。
    - **千張大戶%**=大戶持股比（每日 run_all 已直接顯示，資料來自每週 update_holders）。
- **T16 抗跌強勢**：找「大盤跌時還逆勢強」的股票。
  - **區間漲幅%**=近 10 日累積漲幅（非單日）、**相對大盤%**=贏過大盤多少（正=抗跌/逆勢強）。
  - 用途：強勢族群領頭羊。**已過度延伸(漲>30%)的會自動排除**（不追噴出股，門檻在 config.T16.MAX_RETURN）。
- **⭐ 雙訊號交集**：同時出現在 T11 和 T16 = **法人買且抗跌**，最高信心，優先研究。

### 🚀 成長軌（月營收動能，持有天~數月）
- **T12 月營收動能 (run_t12)**：找「營收年增(YoY)強、且近月動能**加速**」的成長股。
  回測證明「營收不衰退」是組合 edge 的關鍵因子，這是它的**正面選股版**（地雷偵測的反面）。
  - **YoY%**=最新月營收年增；**累計YoY%**=年初至今累計年增；
    **加速度**=YoY−累計YoY（**>0 代表近月成長率高於今年平均 = 動能正在加速**，非一次性）。
  - **站上20MA**=股價也站上月線（市場認同）。
  - 全市場官方月營收 OpenAPI（**免 FinMind、不限流**）；已**排除營建**(完工認列失真)
    與 **YoY 爆表**(去年同月近0的基期效應)雜訊。門檻在 config.T12。
  - → `python -m scripts.run_t12`（每月 10 號後營收公布最新）

### 🏦 主力籌碼綜合 (run_mainforce)
- 找「**主力進駐、散戶退場**」的股票——分點是付費資料，這裡用**免費**的組合達到同樣意圖。
- **主力分** = 法人佔量%（三大法人淨買/成交量）+ 千張大戶週增(pp) + 散戶退場(融資減%)。
  分數高 = 法人買 + 大戶增持 + 散戶退場 = **籌碼往主力集中**。
- 兩種用法：`run_mainforce`（全市場主力進駐排行）、`--stocks 2330`（看單檔籌碼全貌）。
- **漸進加值**：偵測到 FinMind Sponsor token（.env 填 `FINMIND_TOKEN`、等級足夠）→
  **自動多出「分點主力買賣超」欄**（真實券商分點進出），不需改任何程式；沒 token 就走免費模式。
  - → `python -m scripts.run_mainforce`（門檻/權重在 config.MAINFORCE）

### 🟢 長期軌（持有數月~數年）
- **價值+成長+配息**：便宜(低PER/PBR)、領息(殖利率)、穩定(連配息≥5年)、有成長(營收/EPS)。
  - `ROE估%`=賺錢能力(用 PBR/PER 估)、`連配息年`=連續配現金股利年數。
  - ⚠️`建材營造`(營建股)會標註：它營收認列不規律(完工才認)，YoY 會爆高爆低失真；
    **最終清單最多只留 3 檔營建股**(config.LONGTERM.MAX_LUMPY)，避免整張表被營建洗版。
  - `千張大戶%`(來自 run_t30 深掘)：持股≥1000張大戶佔比，高或增加=籌碼集中(先跑 update_holders)。

### 🔴 當沖軌（當天進出）
- **當沖候選(EOD掃描)**：盤後找**高波動+高流動+爆量**的股票，縮小盤中要盯的清單。
  - **當日振幅%**=基準日(最新交易日)的高低差、**均振幅%**=近20日平均振幅(波動大才有價差)、
    **量能倍數**=當日量/20日均量(爆量)。（「當日」指資料的最新交易日，非報告產出當天）
  - ⚠️這是盤後掃描**不是即時訊號**，盤中要自己看；當沖勝率最低、務必嚴設當日停損。

> 💡 **報告日期標示**：每個區塊上方會標「資料截至 YYYY-MM-DD」。
> 尤其 T11 因法人資料對齊，收盤/區間漲幅的基準日可能是**前一個交易日**，別跟你看盤看到的最新單日價搞混。

## 三、環境與風控

- **🚦 多空紅綠燈 (regime)**：用「站上20日均線的股票比例 + 漲跌家數」判斷大盤環境，
  給**建議部位水位**（偏多7~10成 / 震盪2~5成 / 偏空0~2成）。核心：爛環境叫你別硬做。
- **🌍 全球市場 (global_market)**：抓費半/那指/標普/VIX/台幣。**費半(SOX)最重要**——
  台股半導體隔日常跟著費半走。
- **🛡️ 風控試算 (risk_calc)**：給你「該買幾張、停損設哪、停利多少、風險報酬比」。
  原則：先定「這筆最多賠 X%」，用停損距離反推張數，單檔部位上限 25%。
  → `python -m scripts.risk_calc --stock 2206 --account 100萬 --risk 1.5`
- **📋 持股追蹤器 (portfolio)**：記錄你手動下的實單→自動抓即時價算損益，
  到停損/停利價跳 🔔 警示。純本機（data/portfolio.csv，不上傳），不需券商 API。
  → `python -m scripts.portfolio`（看損益）／`add`（新增）／`remove`（移除）
- **🛡️ 盤中持股守衛 (monitor_portfolio)**：盤中掛著跑，持續盯持股，**一觸停損/停利
  就自動推 Telegram 到手機**（每檔只推一次）。不用一直盯電腦。
  → `python -m scripts.monitor_portfolio`
- **🧨 地雷偵測 (run_landmine)**：買進/續抱前的**排雷**檢查（是「排除」不是選股，也不是放空訊號）。
  逐檔查三面紅旗、加權算「風險級（🟢低/🟡中/🟠高/🔴嚴重）」：
  - **財務**：營收動能崩塌、單月營收急墜、近四季轉虧、EPS年增崩、毛利率惡化(年減)。
  - **籌碼**：投信(上市)/外資(上櫃)連續賣超、千張大戶週減(出貨)、融資暴增(散戶接刀)。
  - **技術**：跌破季線(60MA)、相對大盤弱勢。
  - 三種用法：`--holdings` 查我的持股（預設）、`--stocks 2330,2603` 查指定股、
    `--from-daily` 把今天 T11/T16/當沖候選掃一遍（避免買到雷）。
  - → `python -m scripts.run_landmine --holdings`（門檻在 config.LANDMINE）

> 兩種推播分工：盤後 `run_all --notify`（選股+持股結算一次）；盤中 `monitor_portfolio`（持股守衛，觸價才推）。
> 排雷習慣：**要買前先 `--stocks 該檔` 排雷；每週對持股 `--holdings` 排雷一次**（見每日每週操作）。

## 四、盤中與驗證

- **📡 盤中監控 (monitor_intraday)**：TWSE MIS 免開戶即時報價(~20秒延遲)，盤中盯一籃股，
  警示「接近漲跌停/急拉急殺/突破當日高低」。只監控不下單。
- **📲 推播 (run_all --notify)**：跑完把摘要(環境+雙訊號交集+各軌前3**+持股損益/觸停損提醒**)
  推到手機。持股觸停損會排在最前面。用 **Telegram**（Line Notify 已於 2025/3/31 停用）或 Email。
- **🔬 深掘 (run_t30)**：對短名單逐檔補「月營收YoY / EPS / 本益比」，做「籌碼+基本面」二次驗證。
- **📊 回測 (run_backtest / run_validation / run_full_backtest)**：拿歷史驗證訊號有沒有效。
  **已驗證結論**：單看法人沒用；「法人連買+抗跌+營收不衰退」的**組合訊號**有效，
  且**持有數週比幾天好**（5天持有全賠）。

## 五、資料從哪來（都免費）

- **TWSE / TPEX 官方**：全市場日 K、三大法人、融資、估值（上市+上櫃）。
- **FinMind**：逐檔月營收、EPS、配息、多年歷史（免費逐檔，全市場批次要付費）。
- **Yahoo Finance**：全球指數。
- **TWSE MIS**：盤中即時報價（免開戶）。
- 資料存在 `data/stock.db`（SQLite）；報告在 `reports/screener/`。
